# 🍰 Sweet Cake Shop

A professional Cake Shop Management System built using Python, Streamlit and SQLite.

## 📌 Project Overview

Sweet Cake Shop is a web-based cake shop management application.

The application allows users to:

- View available cakes
- Search cakes
- Place cake orders
- Manage cake inventory
- Manage customers
- Track sales and orders
- View an interactive dashboard
- Download sales reports in Excel
- Manage cakes through an Admin Panel

## 🚀 Features

### 🏠 Home
- Welcome page
- Total cakes
- Total orders
- Total customers

### 🍰 Cake Menu
- View all cakes
- Cake name
- Flavor
- Price
- Available stock
- Search cake functionality

### 🛒 Order Cake
